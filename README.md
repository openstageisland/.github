# .github

The organisation-level home for **[Open Stage Island](https://github.com/openstageisland)**.

## Where the actual profile lives

The org landing page at [github.com/openstageisland](https://github.com/openstageisland)
is rendered from **`profile/README.md`** in this repository. That file is the
single source of truth for the venue, how to reach it, and how to play on it.

If you are here to read what this org is, read
**[`profile/README.md`](profile/README.md)**.

## What else is in here

| Path | What it does |
| ---- | ------------ |
| [`profile/README.md`](profile/README.md) | The org landing page. Keep this the only place the org's description lives. |

Host configuration and the Second Life instance setup are kept private. The
public surface is the stage, the site and this profile.

## One rule

**Do not duplicate the profile text here.** A second copy drifts within weeks and
then two landing pages disagree about what the venue is. Edit `profile/README.md`
instead — including the coordinates and the destination-guide blurb, which the
profile owns.
